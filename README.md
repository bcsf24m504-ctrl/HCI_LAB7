# PUCIT HCI Lab 07 — Figma to Website

A responsive multi-section Nova landing page created for HCI Lab 07.

## Included
- `index.html` — complete responsive website (HTML, CSS and JavaScript in one file)
- `.vscode/mcp.json` — Figma remote MCP server configuration

## Lab requirements covered
- Navigation bar
- Hero section with calls to action
- Three-card feature grid
- Contact form with labels and native inputs
- Footer
- Responsive layouts for desktop, tablet and mobile
- Semantic HTML landmarks and accessible form labels
- Hover and keyboard-focus states

## Run locally
Open `index.html` in a browser. No dependencies or build step are required.

## Deploy with GitHub Pages
1. Create a public GitHub repository named `pucit-hci-lab07`.
2. Upload the contents of this folder (upload `index.html`, `.vscode/`, and this README; do not upload the ZIP itself).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then click **Save**.
6. Wait for GitHub Pages to publish and copy the URL shown in the Pages section.

## Figma
The editable design file is linked separately in the lab submission. Set its sharing access to **Anyone with the link — can view** before submitting.
